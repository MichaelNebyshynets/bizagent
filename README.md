# БизнесПомощник

1. Скачайте **BizAgent-Setup.exe** со страницы [выпусков программы](https://github.com/andreimikhnovets/bizagent/releases), когда там появится версия для Windows.
2. Запустите файл двойным щелчком и следуйте подсказкам. Установка выполняется для вашей учётной записи Windows.
3. Откройте ярлык **БизнесПомощник**. При первом запуске оставьте окно открытым и дождитесь загрузки компонентов ИИ. Программа предложит придумать пароль длиной от 12 до 128 символов и откроет браузер.
4. Войдите как **owner@uyut.by** с паролем, который вы задали. В базе уже есть учебные компании и продажи, на которых можно попробовать программу.

## Что потребуется

Версия предназначена для Windows 10/11 x64. Для первоначальной настройки нужны интернет и как минимум 13 ГиБ свободного места после установки. Для локального ИИ рекомендуется 16 ГБ оперативной памяти. Скорость ответа зависит от компьютера. Установщик без цифровой подписи может вызвать предупреждение SmartScreen.

Для повторного запуска откройте тот же ярлык. Для остановки нажмите **Enter** в окне программы после открытия браузера. Перед обновлением остановите программу и запустите новый установщик. Для удаления используйте раздел «Приложения» в параметрах Windows. Заказы, загруженные файлы, модели и настройки сохраняются в папке `%LOCALAPPDATA%\BizAgent\data`. Здесь же находятся журналы `services.log` и `postgres.log`.

## Как пользоваться

- В разделе обзора отображаются показатели компании. В аналитике выберите нужный период.
- В заказах найдите продажу и откройте её состав. Для загрузки продаж скачайте шаблон CSV, заполните его, просмотрите результат проверки и подтвердите импорт. Загруженные партии доступны в истории.
- В чате задайте вопрос или приложите документ. Проверьте предложенное ассистентом действие перед подтверждением.
- В закупках можно составить заказ поставщику. В разделе сотрудников владелец управляет доступом и ролями.
