# БизнесПомощник РБ: фронтенд (React + Vite)

Проще всего запускать весь проект из корня репозитория: `python run.py` (см. README в корне).

Отдельно: `npm install`, затем `npm run dev` (http://localhost:5173). Бэкенд должен работать на порту 8000.

| Что | Состояние |
|---|---|
| Вход (`Login.jsx`) | `POST /auth/login` по email (демо, без пароля) |
| Чат (`Chat.jsx`) | история чатов с сервера, загрузка файлов, подтверждение действий, ответы в markdown |
| Дашборд, аналитика, база знаний, профиль | демо-данные, к бэкенду не подключены |

Сквозной тест чата против живого бэкенда: поднимите бэкенд в режиме mock (`python run.py --mock --no-browser` из корня или `DB_BACKEND=mock uvicorn app.main:app --port 8000` в `bizagent/`), затем здесь `npm run test:e2e`.
